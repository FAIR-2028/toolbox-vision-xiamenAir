# 项目目录导航

- `app/`：Next.js 页面入口与后端 API。
- `public/inspection.html`：当前工作台页面；`public/samples/` 为网页图片。
- `lib/`、`config/`：业务逻辑、接口契约、工具清单与演示配置。
- `tests/`、`scripts/`：测试和构建辅助脚本。
- `docs/`：需求、v1.2 参考资料与验收记录。
- `bootstrap/`、`deployment/`：环境检查与部署参考模板；实际 Docker 配置仍在根目录。
- `samples/`：原始样例资料，保留原位以免影响资料引用。
- `archive/backups/`：13 份历史源码备份，保留原目录层级和文件名；当前业务源码未移动、未覆盖。
- `logs/`：后续运行日志存放位置。
- `node_modules/`、`.next/`：依赖和构建输出。

根目录的启动入口、环境说明与配置文件保留原路径，避免破坏已有操作指引。

现有根目录的 6 份日志仍被运行进程占用，暂留原位；停止对应服务后再归档，不强行停止服务。`docs/verification/` 中的日志属于验收证据，保留原位置。

历史源码备份已移出 `public/`，避免后续随静态资源公开和打包。归档和日志目录已从 Docker 构建上下文排除。
