# 机务小工具视觉检测改造计划

## 一、目标效果

建设一套面向两套混合使用小工具箱的现场演示系统，使用**一个 YOLO 模型**统一识别两套工具箱中的小工具空槽。

系统完成以下演示链路：

> 上传图片 → 图像质量检查 → YOLO 空槽检测 → 界面告警 → 人员登记与结果确认 → 检测历史查询

大工具的 RFID 状态在界面中提供模拟数据和模拟告警，用于展示视觉检测与 RFID 业务信息的协同方式。RFID 设备接入属于后续现场集成内容。

## 二、数据与模型

### 预计效果

- 两套小工具箱的照片进入同一个训练数据集。
- 一个 YOLO 模型覆盖两套混合使用的小工具箱。
- 模型识别小工具空槽并返回位置框、置信度和告警候选。
- 训练数据同时用于模型训练和后续上传测试。
- 生成一组固定测试图片，覆盖工具齐全、不同小工具缺失、多个空槽和多种拍摄角度。

### 实施路线

1. 采集两套小工具箱的现场照片。
2. 对小工具空槽进行统一标注。
3. 按训练用途和上传测试用途整理图片与标注。
4. 使用 YOLO 训练一个统一模型。
5. 导出 ONNX 权重并接入现有推理服务。
6. 使用固定测试图片验证上传、检测框、置信度和告警展示。

## 三、图像质量检查

### 预计效果

系统在 YOLO 推理前检查上传图片质量，识别以下情况：

- 清晰度偏低
- 运动模糊
- 亮度偏低
- 过曝
- 工具箱区域缺失
- 关键区域遮挡
- 工具箱主体偏离画面

质量合格时进入 YOLO 检测。质量需要改善时，页面显示具体原因、重拍建议和当前状态。

### 实施路线

1. 采用成熟的图像质量评价算法和机器视觉特征完成清晰度、亮度、曝光、完整度和主体区域检查。
2. 将质量检查封装为独立推理模块，输出质量分数、问题类型和处理建议。
3. 在上传流程中加入“质量检查 → 检测处理”的顺序。
4. 为每种质量状态准备固定测试图片，验证放行、重拍提示和重新上传流程。
5. 根据现场测试结果调整质量阈值。

## 四、RFID 与告警演示

### 预计效果

前端展示两类业务信息：

- **视觉告警**：YOLO 识别小工具空槽后生成候选告警。
- **RFID 告警**：页面读取模拟 RFID 状态，展示大工具在位、离位和读取异常。

界面展示告警级别、告警时间、工具名称、来源、处理状态和人员确认结果。RFID 部分采用模拟数据，重点演示业务流程和页面呈现。

### 实施路线

1. 设计一组可切换的 RFID 模拟状态。
2. 设计大工具在位、离位、读取异常三类模拟场景。
3. 将视觉结果和 RFID 结果汇总到统一告警列表。
4. 增加告警确认、处理人登记和处理时间记录。
5. 使用多组固定场景完成现场演示。

## 五、规范化业务界面

### 预计效果

系统提供接近实际使用的现场工作流：

- 检测人员登记
- 工具箱检测任务创建
- 图片上传和质量状态
- YOLO 检测结果
- RFID 模拟状态
- 告警列表
- 人工确认和处理状态
- 检测时间戳
- 历史检测记录查询

### 实施路线

1. 建立检测任务和检测人员信息。
2. 为每次上传生成检测编号和时间戳。
3. 保存图片质量结果、模型版本、检测框、告警和确认记录。
4. 增加历史记录页面，支持按时间、人员和告警状态查看。
5. 用固定业务案例演示正常、视觉告警、RFID 告警、图像质量待重拍和人工确认等状态。

## 六、Jetson Xavier NX 部署

### 预计效果

将训练完成的 YOLO 模型部署到现有 Jetson Xavier NX 环境，在设备上运行网页服务和图像推理服务。

页面显示设备运行状态、模型版本、推理后端和单次检测耗时。

### 实施路线

1. 将 YOLO 权重转换为适配 Jetson 的 ONNX 或 TensorRT 格式。
2. 编写 Jetson 推理适配器，统一图片输入、模型输出和检测框格式。
3. 将网页服务、推理适配器和模型部署到现有 NX 环境。
4. 完成设备启动、图片上传、质量检查、YOLO 检测和告警展示的端到端验证。
5. 记录设备上的模型版本、推理耗时和运行状态。

## 七、交付顺序

1. 采集两套混合小工具箱照片并完成统一标注。
2. 训练一个 YOLO 模型并导出部署格式。
3. 接入图像质量检查算法。
4. 完成上传测试图片和检测结果展示。
5. 加入 RFID 模拟状态和模拟告警。
6. 完成检测人员、时间戳、告警处理和历史查询。
7. 将模型、推理适配器和网页服务部署到 Jetson Xavier NX。
8. 使用固定业务案例完成现场演示验收。

## 八、前端界面优化

### 预计效果

将当前页面升级为面向机务现场的专业检测工作台，围绕人员登记、任务创建、图片上传、质量检查、YOLO 检测、RFID 模拟、告警确认和历史查询组织界面。

### 页面结构

1. 顶部系统栏展示系统名称、运行环境、模型版本、推理设备、服务状态、当前人员和时间。
2. 左侧功能导航包含现场检测、告警中心、检测历史、RFID 模拟、系统状态和使用说明。
3. 主检测区采用三栏结构：左栏展示任务信息，中栏展示图片与检测框，右栏展示视觉告警、RFID 模拟状态和确认操作。
4. 检测框、告警卡片和任务信息保持联动，点击框体时同步高亮对应告警。
5. 历史页面使用表格与详情面板，展示检测编号、时间、人员、图片质量、YOLO 结果、RFID 模拟状态和处理记录。

### 视觉与交互

- 采用深蓝工业主色、浅灰蓝工作区、橙色操作强调、红色告警提示和绿色完成状态。
- 统一卡片、状态标签、表格、按钮、间距、字体和图标规范。
- 上传区域支持点击选择、拖拽上传、图片预览、进度反馈和重新上传。
- 页面按“上传完成 → 质量检查 → YOLO 检测 → 结果确认”展示当前步骤。
- 质量结果显示具体原因和拍摄建议，例如保持工具箱完整入镜、提高照明、减少手持抖动和调整拍摄角度。
- 检测框展示编号、置信度、位置和待确认状态，支持人工确认和误报标记。
- 告警卡片展示编号、来源、工具名称、时间、当前状态、处理人员和备注。
- RFID 模拟页面提供大工具全部在位、大工具离位、读取异常和多个状态变化等场景切换。

### 设备与响应式适配

- 系统状态区域展示 Jetson Xavier NX、推理后端、模型名称与版本、服务运行时间和最近一次推理耗时。
- 桌面端采用三栏工作台，平板端调整为上下分区，小屏端采用单列流程卡。
- 主要操作按钮保持适合触控的尺寸，键盘操作保留清晰焦点状态，图片和控件提供可读的文字说明。
- 页面信息优先呈现检测任务、图片结果和告警状态，详细记录通过详情面板展开。

### 实施路线

1. 重构页面信息架构，建立顶部栏、侧边导航和检测工作台。
2. 提取统一的状态标签、告警卡片、任务卡片和按钮样式。
3. 完成上传、质量检查、YOLO 检测和人工确认的流程化展示。
4. 增加 RFID 模拟场景和综合告警面板。
5. 增加检测人员、时间戳、处理备注和历史记录页面。
6. 加入 Jetson 设备状态和模型运行信息。
7. 完成桌面端、平板端和小屏端适配。
8. 使用固定业务案例完成现场演示验收。

## 九、最终演示场景

演示人员进入系统后，在顶部查看设备状态，在左侧创建检测任务，填写人员信息并上传图片。中间区域展示质量检查和 YOLO 结果，右侧区域展示视觉告警与 RFID 模拟告警。演示人员点击告警框查看详细信息，完成确认和处理登记，最后在历史页面回看整次检测记录。
